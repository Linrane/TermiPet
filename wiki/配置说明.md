# 配置说明

TermiPet 的所有配置都存储在 `~/.termipet/config.toml` 文件中。

## 配置文件路径

| 系统 | 路径 |
|------|------|
| Linux / macOS | `~/.termipet/config.toml` |
| Windows | `C:\Users\<用户名>\.termipet\config.toml` |

可通过环境变量 `TERMIPET_DATA` 自定义目录：

```bash
# Linux / macOS
export TERMIPET_DATA=/custom/path

# Windows (PowerShell)
$env:TERMIPET_DATA = "D:\custom\path"
```

## 配置项一览

```toml
theme = "cyberpunk"            # 主题风格
language = "zh"                # 界面语言
auto_save = true               # 自动保存
notification = true            # 通知提醒
decay_multiplier = 1.0         # 属性衰减倍率
animation_speed = "normal"     # 动画速度
```

## 详细说明

### theme — 主题

可选值：

| 主题 | 风格 | 说明 |
|------|------|------|
| `cyberpunk` | 赛博朋克 | 默认主题，青色+品红+黄色 |
| `pastel` | 柔粉 | 柔和的粉色系，适合休闲 |
| `minimal` | 极简 | 纯黑白配色，简洁清爽 |

### language — 语言

| 值 | 说明 |
|----|------|
| `zh` | 中文（默认） |
| `en` | 英文 |

### auto_save — 自动保存

- `true`（默认）— 每次操作后自动保存
- `false` — 手动保存（暂未实现手动保存命令）

### notification — 通知

- `true`（默认）— 显示成就解锁、阶段变化等通知
- `false` — 静默模式，不显示通知

### decay_multiplier — 属性衰减倍率

控制属性随时间衰减的速度：

| 值 | 效果 |
|----|------|
| `0.5` | 衰减减半（休闲模式） |
| `1.0` | 正常速度（默认） |
| `2.0` | 衰减翻倍（挑战模式） |
| `5.0` | 快速衰减（适合测试） |

> **测试建议**：将此值设为 `5.0` 或更高，可以快速体验成长阶段变化。

### animation_speed — 动画速度

| 值 | 说明 |
|----|------|
| `fast` | 快速动画 |
| `normal` | 正常速度（默认） |
| `slow` | 慢速动画，适合欣赏 |

## 重置配置

如果配置文件损坏，删除 `config.toml` 文件后下次启动 TermiPet 会自动生成默认配置：

```bash
# Linux / macOS
rm ~/.termipet/config.toml

# Windows
del %USERPROFILE%\.termipet\config.toml
```

> 删除配置文件**不会**影响宠物数据（数据库独立存储）。

## 数据库

宠物数据存储在 SQLite 数据库中：

```
~/.termipet/termipet.db
```

### 数据库表

| 表名 | 说明 |
|------|------|
| `species` | 物种定义 |
| `pets` | 宠物实体 |
| `items` | 物品定义 |
| `homes` | 家园数据 |
| `skills` | 宠物技能 |
| `quests` | 任务进度 |
| `achievements` | 成就进度 |
| `maze_states` | 迷宫状态 |
| `story_fragments` | 故事碎片 |
| `inventory` | 背包物品 |

SQLite 使用 WAL 模式，保证读写并发安全。

> **不要手动编辑数据库**，除非你清楚自己在做什么。
