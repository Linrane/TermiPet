# 经济系统

TermiPet 拥有完整的双货币经济体系，包含商店买卖、物品制作和收藏系统。

## 双货币

### 💰 金币 (Coins)

- **用途**：购买物品、升级家园、制作装备
- **获取方式**：
  - 探险战斗胜利
  - 打开迷宫宝箱
  - 出售物品
  - 初始赠送 100 金币

### ✨ 星尘 (Stardust)

- **用途**：稀有货币，用于高级交易
- **获取方式**：
  - 解锁成就
  - 迷宫宝箱（第 4 层以后）
  - 完成特殊任务
  - 回答谜题

## 稀有度系统

| 稀有度 | 说明 |
|--------|------|
| 普通 | 基础物品，商店常见 |
| 稀有 | 较少出现，效果更强 |
| 传说 | 极为稀有，通常来自迷宫深层 |

## 商店操作

```bash
pet shop list               # 查看商店物品
pet shop buy 基础饲料       # 购买物品（支持中文名）
pet shop buy basic_food     # 也支持 key
pet shop sell 生鱼           # 出售背包中的物品
pet inventory               # 查看背包
```

## 经济策略

1. **前期** — 精打细算，优先购买基础饲料和治愈药水
2. **中期** — 通过迷宫探险积累金币和稀有材料
3. **后期** — 自给自足，通过制作和探险获取高价值物品
4. **装备投资** — 优先购买能提升探险效率的装备
5. **材料囤积** — 稀有材料（数据碎片、魔法水晶、星辰金属）用于家园升级
