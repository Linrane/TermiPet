# 日常事件系统

## 概述

日常事件系统（2.1 新增）受旅行青蛙启发 — 当你不在的时候，你的灵兽会自主行动。等你回来后，可以查看它做了什么。

## 事件触发机制

### 什么时候生成事件？

| 条件 | 说明 |
|------|------|
| 离线时间 | 超过 **30 分钟** 才开始积累事件 |
| 时间上限 | 最多计算 **24 小时** 的离线时间 |
| 事件频率 | 每小时最多 **1 个** 事件 |
| 未读上限 | 最多 **5 个** 未读事件 |

### 如何触发检查？

当你执行以下命令时，系统会自动检查离线时间并生成事件：
- `pet status` — 查看状态时
- `pet daily` — 查看日常事件报告时

## 命令用法

### 查看事件报告

```bash
pet daily
```

显示所有未读的日常事件列表，包括时间、类别、标题和摘要。

### 查看历史事件

```bash
pet daily --all
```

显示所有历史事件（包括已读的），最近 20 条。

### 阅读事件详情

```bash
pet daily read 1    # 阅读第 1 条事件
```

显示事件的完整故事文本和具体属性变化。阅读后自动标记为已读。

### 标记全部已读

```bash
pet daily clear
```

## 事件触发条件

部分事件有额外触发条件：

- **外出探索类**：需要非蛋期，部分需要达到特定成长阶段
- **家园日常类**：需要非蛋期，部分事件有属性条件（如饥饿度<60才能触发"厨房偷吃"）
- **社交互动类**：需要达到少年阶段以上，部分需要足够的金币
- **天气事件**：需要非蛋期，"打雷被吓到了"仅限胆小或温柔性格
- **成长事件**：部分需要特定成长阶段或属性条件
- **物种特色**：仅限对应物种，部分需要达到高成长阶段

## 设计理念

日常事件系统的核心设计理念是 **"异步陪伴"**：

1. **旅行青蛙灵感** — 你不需要时刻在线，灵兽有自己的生活
2. **丰富叙事** — 每个事件都有完整的故事文本，让灵兽更加鲜活
3. **轻量影响** — 事件对属性的影响很小（±3~15），不会破坏游戏平衡
4. **物种差异化** — 每个物种有独特的专属行为，增加重玩价值
5. **成长解锁** — 随着灵兽成长，会解锁更多种类的日常事件
