# 家园系统

每个灵兽都拥有自己的家园，包含 5 间可升级的房间。升级房间可以解锁新功能、提升养成效率。

## 基本操作

```bash
pet home status              # 查看家园状态
pet home upgrade 卧室        # 升级房间（支持中文名）
pet home upgrade bedroom     # 也支持英文名
pet home craft 烤鱼          # 制作物品
```

## 制作系统

使用 `pet home craft <配方>` 制作物品。需要先升级对应房间到足够等级。

制作需要消耗背包中的材料。可在商店购买基础材料，也可在迷宫探险中获取稀有材料。

## 升级策略

1. **优先升级厨房** — 解锁食物配方，减少商店购买支出
2. **其次升级卧室** — 提升精力恢复，支持更长时间的探险
3. **中期解锁工坊** — 制作装备提升探险能力
4. **后期解锁花园** — 自给自足获取材料
5. **最终解锁图书室** — 技能研究提供额外加成

## 家具与装饰

- 家园拥有装饰度评分 (`decoration_score`)
- 家具可以增加装饰度（具体家具系统待扩展）

## 花园种植

花园解锁后拥有种植槽，可以种植材料：

- 种植后需等待一定时间才能收获
- 花园等级越高，种植槽数量越多
- 具体种植配方见制作系统
