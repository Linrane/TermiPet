# 迷宫探险

TermiPet 的迷宫探险采用 **Roguelite** 设计 — 随机生成地图、永久死亡（失败撤退保留战利品）、难度逐层递增。

## 基本操作

```bash
pet adventure start              # 从第 1 层开始探险
pet adventure start --depth 5    # 从第 5 层开始
pet adventure move w             # 向上移动 (w/a/s/d)
pet adventure move 左            # 中文方向也支持
pet adventure auto               # 自动探险 10 步
pet adventure auto 20            # 自动探险 20 步
pet adventure status             # 查看当前探险状态
pet adventure retreat            # 撤退（保留战利品）
```

## 迷宫地图

迷宫尺寸为 **15×10**，使用递归回溯法随机生成。每次探险都会生成全新的地图。

### 单元格类型

| 符号 | 类型 | 说明 |
|------|------|------|
| `#` | 墙壁 | 不可通行 |
| `.` | 地板 | 空旷走廊，安全 |
| `S` | 起点 | 探险开始位置 |
| `E` | 出口 | 进入下一层 |
| `C` | 宝箱 | 打开获得金币/物品 |
| `T` | 陷阱 | 触发后损失健康值 |
| `M` | 怪物 | 触发战斗事件 |
| `?` | 谜题 | 回答问题获得奖励 |
| `$` | 商店 | 迷宫内商店（每 5 层出现） |
| `!` | 故事 | 发现故事碎片 |

### 地图显示

- 已探索区域正常显示
- 未探索区域标记为未知
- 当前位置高亮标记
- `C`/`M` 格子在触发后变为 `.`

## 进入条件

| 条件 | 要求 |
|------|------|
| 阶段 | 不能是蛋阶段 |
| 精力 | >= 15 |
| 健康 | >= 10 |

进入时消耗 **5 点精力**，每移动一格消耗 **1.5 点精力**。

## 难度递增

层数越高，难度越大：

| 要素 | 变化规则 |
|------|---------|
| 宝箱数量 | `max(1, 3 - 层数÷5)` — 越深越少 |
| 陷阱数量 | `min(层数÷2 + 1, 6)` — 越深越多 |
| 怪物数量 | `min(层数÷3 + 1, 5)` — 越深越多 |
| 谜题 | 第 3 层以后出现 |
| 迷宫商店 | 每 5 层出现 |

## 事件详解

### 宝箱 (C)

随机获得 2-3 种奖励：

| 奖励类型 | 说明 |
|---------|------|
| 金币 | 10+层数×2 到 20+层数×5 |
| 星尘 | 第 4 层以后有概率获得 1 颗 |
| 材料 | 数据碎片、草药、铁锭等 |

> 「寻宝之鼻」技能可以增加额外掉落！

### 陷阱 (T)

- 造成 `5+层数` 到 `10+层数×2` 点伤害
- 健康归零则自动撤退
- 「影步」等技能可以提高回避率

### 怪物 (M)

战斗采用**剪刀石头布变体**（攻击/防御/技能），胜负关系：

- 攻击克技能，技能克防御，防御克攻击
- 相同则平局，双方各受少量伤害
- 「战斗姿态」等技能可以提高胜率

**战斗结果：**

| 结果 | 效果 |
|------|------|
| 胜利 | 获得 10+层数×3 经验，10+层数到 25+层数×3 金币；清除怪物格 |
| 平局 | 损失 2-5 健康，获得 3-8 金币 |
| 失败 | 损失 8+层数到 15+层数×2 健康 |
| 击败 | 健康归零，自动撤退 |

### 谜题 (?)

回答问题获得奖励，示例：
- 数学题：`1 + 1 = ?` → 金币 ×30
- 世界观题：`灵兽孵化需要几天？` → 草药 ×3
- 知识题：`数据裂隙中最危险的生物是？` → 星尘 ×1

### 出口 (E)

- 获得 20+层数×5 探险经验
- 自动进入下一层，生成新迷宫
- 第 5 层和第 10 层解锁特殊故事碎片
- 更新相关任务进度

### 故事碎片 (!)

随机发现一个故事碎片，加入你的故事收藏。

## 自动探险

```bash
pet adventure auto       # 默认 10 步
pet adventure auto 20    # 指定步数（最多 20 步）
```

自动探险特点：
- **智能寻路** — 优先走向未探索的区域
- **自动停止** — 精力 < 5 或健康 < 5 时停止
- **到达出口** — 找到出口时自动进入下一层并停止

## 撤退机制

```bash
pet adventure retreat
```

- 迷宫内的临时战利品（loot）全部转入背包
- 记录撤退时的层数
- 探险状态重置，下次需重新开始

## 探险策略

1. **保持高精力** — 探险前确保精力充足，必要时先睡觉
2. **带足药品** — 背包里准备治愈药水
3. **利用技能** — 被动技能在迷宫中持续生效
4. **及时撤退** — 健康低于 20 时考虑撤退
5. **装备加成** — 装备可以提升探险中的生存能力
6. **自动探险** — 资源充裕时用自动探险刷经验和金币
