# 技能系统

每个灵兽可以学习技能来获得各种被动加成，影响探险、养成和战斗效率。

## 基本操作

```bash
pet skill list               # 查看可学习的技能树
pet train quick_heal         # 学习/升级技能（用 key）
pet train 快速治愈            # 也支持中文名
```

## 技能点获取

技能点通过**成长阶段变化**获得：

| 阶段变化 | 获得技能点 |
|---------|-----------|
| 蛋 → 幼年 | 1 |
| 幼年 → 少年 | 2 |
| 少年 → 成年 | 3 |
| 成年 → 巅峰 | 3 |
| 巅峰 → 传奇 | 5 |
| 传奇 → 远古 | 10 |
| **总计** | **24** |

## 技能学习规则

- **阶段限制**：蛋阶段无法学习技能
- **物种限制**：某些技能仅限特定物种学习
- **等级上限**：每个技能最高 5 级
- **费用递增**：学习消耗基础费用，升级费用 = 基础费用 × (当前等级 + 1)

## 技能加点建议

### 探险流
优先升级：`treasure_nose` > `shadow_step` / `battle_stance` > `lucky_star`

### 养成流
优先升级：`quick_heal` > `purr_therapy` / `comfort_song` > `forager`

### 战斗流
优先升级：`battle_stance` > `tough_skin` > `night_hunter`

### 均衡流
各技能均匀分配，先点到 2-3 级再集中升级核心技能

## 被动加成汇总

被动技能的效果在以下场景自动生效：
- **迷宫探险**：战斗胜率、陷阱回避、宝箱掉落率
- **日常互动**：喂食效果、健康恢复、快乐恢复
- **属性成长**：智力成长、精力消耗
- **探险经验**：经验倍率加成
