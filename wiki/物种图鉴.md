# 物种图鉴

TermiPet 2.0 共有 **5 个物种**，每个物种拥有独特的初始属性、衰减速率、专属技能树和天赋池。

## 物种一览

### 🐱 猫型灵兽 (cat)

> 来自数据裂隙的影子层，灵敏神秘，擅长躲避陷阱。

**初始属性：**

| 属性 | 初始值 | 特点 |
|------|--------|------|
| 饱腹度 | 65 | 稍低 |
| 快乐值 | 75 | 较高 |
| 清洁度 | 85 | 最高 |
| 健康值 | 80 | 较高 |
| 精力 | 75 | 较高 |
| 智力 | 65 | 中等 |
| 亲密度 | 20 | 标准 |
| 体质 | 60 | 中等 |

**衰减特点：** 快乐衰减慢（×0.9），清洁衰减慢（×0.7），饥饿衰减稍快（×1.1）

**专属技能树：**
1. `quick_heal` — 快速治愈
2. `treasure_nose` — 寻宝之鼻
3. `shadow_step` — 影步（陷阱回避）
4. `purr_therapy` — 呼噜疗法
5. `night_hunter` — 夜间猎手
6. `lucky_star` — 幸运之星

**天赋池：** 大胃王、探险家、夜猫子、甜睡者

**适合玩家：** 喜欢探险与收集，偏好高快乐成长、低维护成本的玩家。

### 🐶 犬型灵兽 (dog)

**初始属性：**

| 属性 | 初始值 | 特点 |
|------|--------|------|
| 饱腹度 | 70 | 中等 |
| 快乐值 | 70 | 中等 |
| 清洁度 | 70 | 中等 |
| 健康值 | 90 | 高 |
| 精力 | 80 | 高 |
| 智力 | 55 | 较低 |
| 亲密度 | 30 | 较高 |
| 体质 | 80 | 高 |

**衰减特点：** 全部属性衰减标准偏快，消耗较多食物，适合活跃玩家

**专属技能树：**
1. `quick_heal` — 快速治愈
2. `loyal_guard` — 忠诚守护
3. `nose_track` — 追踪嗅觉
4. `battle_stance` — 战斗姿态
5. `tough_skin` — 坚韧皮肤
6. `comfort_song` — 安慰之歌

**天赋池：** 大胃王、铁胃、自愈力、社交达人

**适合玩家：** 喜欢战斗和冒险，偏好高血量高防御的前线型玩家。

| 体质 | 100 | 最高 |

## 如何选择？

| 偏好 | 推荐物种 |
|------|---------|
| 低维护、少操心 | 机械型 |
| 高战斗力、前线探险 | 犬型 |
| 高成长、快速进化 | 猫型 |
| 高智力、技能流 | 神秘型 |
| 高精力、探索流 | 鸟型 |

> 每种物种都可以培养到远古阶段，选择你最喜欢的就好！你也可以同时领养多只宠物（使用 `pet list-pets` 和 `pet switch <ID>` 切换）。
