# 常见问题

## 安装与运行

### Q: 安装后输入 `pet` 命令提示 "命令未找到"

**A:** 确认以下几点：
1. 使用 `pip install -e .` 安装（注意最后的 `.`）
2. Python Scripts 目录已加入系统 PATH
3. 尝试使用 `python -m termipet.main` 直接运行
4. 虚拟环境已激活（如果使用了 venv）

### Q: 提示 "ModuleNotFoundError: No module named 'rich'"

**A:** 依赖未正确安装，运行：
```bash
pip install rich click sqlalchemy toml apscheduler
# 或
pip install -r requirements.txt
```

### Q: 支持哪些 Python 版本？

**A:** Python >= 3.10。推荐使用 3.10、3.11 或 3.12。

## 游戏机制

### Q: 蛋怎么孵化？

**A:** 蛋阶段需要等待 **1 天**（游戏内时间）才能自动孵化为幼年。游戏内时间在每次执行命令时根据真实时间差累计。

**快速孵化方法**：修改 `~/.termipet/config.toml`，设置 `decay_multiplier = 10.0`，然后执行任意命令（如 `pet status`），时间会加速流逝。

### Q: 属性一直掉怎么办？

**A:** 属性会随时间自然衰减。解决方案：
1. 定期喂食（恢复饱腹度）
2. 定期玩耍（恢复快乐值）
3. 定期清洁（恢复清洁度）
4. 睡觉（恢复精力和健康）
5. 将 `decay_multiplier` 调低以减缓衰减

### Q: 宠物健康归零了会怎样？

**A:** 健康归零时：
- 在迷宫中：自动撤退
- 在日常状态：不会死亡，但需要尽快治疗

### Q: 可以同时养多只宠物吗？

**A:** 可以！
```bash
pet adopt dog --name "旺财"    # 领养新宠物（当前宠物变为休眠）
pet list-pets                   # 查看所有宠物
pet switch 2                    # 切换到 ID 为 2 的宠物
```

### Q: 属性的衰减在离线时也在计算吗？

**A:** 是的。每次执行命令时会计算距离上次更新的时间差，最长计算 **7 天**的离线时间。

## 迷宫探险

### Q: 迷宫探险失败了会怎样？

**A:** 迷宫中健康归零会自动撤退，迷宫内的临时战利品（loot）会全部转入背包。不会丢失已获得的物品。

### Q: 撤退后迷宫进度还在吗？

**A:** 不在。撤退后迷宫状态重置，下次需要重新开始。已获得的金币和物品已保存到背包。

### Q: 自动探险和手动探险有什么区别？

**A:** 自动探险是 AI 控制移动，优先走向未探索区域。战斗结果仍然是随机的，不会因为自动模式而获得额外优势。

### Q: 迷宫最多有多少层？

**A:** 最多 **20 层**。层数越高，陷阱和怪物越多，宝箱越少。

## 家园与制作

### Q: 工坊、花园、图书室怎么解锁？

**A:** 它们的初始等级为 0，需要使用 `pet home upgrade <房间>` 命令，花费金币和材料来解锁到等级 1。

### Q: 制作物品需要什么条件？

**A:** 需要：
1. 对应房间升级到足够等级
2. 背包中有足够的材料

## 数据与配置

### Q: 数据存在哪里？可以备份吗？

**A:** 所有数据在 `~/.termipet/` 目录下。直接复制整个目录即可备份：
```bash
cp -r ~/.termipet ~/.termipet_backup
```

### Q: 如何重新开始游戏？

**A:** 删除数据目录即可：
```bash
rm -rf ~/.termipet
```
下次启动 TermiPet 会自动重新创建。

> **注意：此操作不可逆！**

### Q: 可以在不同电脑上同步数据吗？

**A:** 目前不支持云同步。你可以手动复制 `~/.termipet/termipet.db` 文件来实现。

## 语言与国际化

### Q: 如何切换到英文界面？

**A:** 三种方式：
```bash
pet --lang en                     # 命令行参数（单次生效）
```
或在 `~/.termipet/config.toml` 中设置 `language = "en"` 永久生效。

### Q: 翻译不完全怎么办？

**A:** 2.2 版本已将全部 CLI 输出、错误消息、状态面板翻译为英文。如发现未翻译的字符串，请在 [GitHub Issues](https://github.com/Linrane/TermiPet/issues) 提交。

### Q: 支持其他语言吗？

**A:** 目前只支持中文（zh）和英文（en）。如需添加其他语言，欢迎贡献翻译。

## 日常事件

### Q: 日常事件是什么？

**A:** 当你离线超过 30 分钟后，你的灵兽会自主进行各种活动（如外出探索、在家捣蛋、和其他灵兽互动等）。等你回来执行 `pet status` 或 `pet daily` 时，就能看到它都做了什么。

### Q: 日常事件会影响属性吗？

**A:** 会的，但影响很小（通常 ±3~15 点）。正面事件会恢复少量属性，负面事件会轻微降低。不用担心宠物因为你不在而变弱太多。

### Q: 如何查看日常事件？

**A:**
```bash
pet daily            # 查看未读事件报告
pet daily read 1     # 阅读第 1 条事件的详情
pet daily --all      # 查看所有历史事件
pet daily clear      # 标记全部已读
```

### Q: 为什么有时候离线很久但没有事件？

**A:** 可能的原因：
1. 未读事件已达上限（5 条）—— 需要先阅读或清除
2. 离线时间不足 30 分钟
3. 没有满足触发条件的事件（蛋期、部分事件需要特定阶段或属性）
