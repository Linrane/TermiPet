# 快速开始

本页指导你从零开始安装并运行 TermiPet 2.1。

## 环境要求

- **Python** >= 3.10（3.10、3.11、3.12 均可）
- **pip**（Python 包管理器）

检查 Python 版本：

```bash
python --version
# 或
python3 --version
```

## 安装方式

### 方式一：从源码安装（推荐）

```bash
# 1. 克隆仓库
git clone https://github.com/Linrane/TermiPet.git
cd TermiPet

# 2. 创建虚拟环境（可选但推荐）
python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

# 3. 安装（开发模式）
pip install -e .
```

### 方式二：直接安装依赖

```bash
git clone https://github.com/Linrane/TermiPet.git
cd TermiPet
pip install -r requirements.txt
```

## 验证安装

```bash
pet --help
```

你应该看到 TermiPet 的帮助信息，包含所有可用命令。

## 你的第一个宠物

### 1. 领养

```bash
pet adopt cat --name "小橘"
```

可用物种：`cat`（猫型）、`dog`（犬型）、`bird`（鸟型）、`mech`（机械型）、`mystery`（神秘型）

### 2. 查看状态

```bash
pet status
```

你会看到宠物的 ASCII 形象、属性条和基本信息。

### 3. 第一次互动

```bash
pet feed       # 喂食
pet play       # 玩耍
pet clean      # 清洁
```

### 4. 睡觉等待孵化

```bash
pet sleep 4    # 睡觉 4 小时
```

> 蛋阶段需要等待 1 天（游戏内时间）才能孵化为幼年。你可以修改配置中的 `decay_multiplier` 来加速。

### 5. 开始探险

孵化后就可以带宠物去探险了：

```bash
pet adventure start
pet adventure auto
```

## 数据存储位置

所有游戏数据保存在 `~/.termipet/` 目录下：

| 文件 | 说明 |
|------|------|
| `termipet.db` | SQLite 数据库（所有宠物数据） |
| `config.toml` | 用户配置 |
| `events.log` | 事件日志 |

可通过环境变量 `TERMIPET_DATA` 自定义目录位置：

```bash
export TERMIPET_DATA=/custom/path
```
